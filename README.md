# AI Customer Service

A mini project built to practice RAG (Retrieval-Augmented Generation) architectures, document chunking strategies, and vector embeddings.

## Tech Stack

- **Framework:** Next.js
- **Backend:** Convex (Realtime Database & Vector Search)
- **AI/LLM:** Gemini & RAG
- **UI:** TailwindCSS, Shadcn UI
- **Architecture:** Monorepo (Turborepo)

## Key Features

- **Smart RAG System:** AI answers queries based on custom knowledge base documents uploaded by your team.
- **Human-in-the-loop:** Seamless handover from AI to human agents when complex issues arise.
- **Realtime Tracking:** Live monitoring of all conversations to ensure prompt human intervention.
- **High Efficiency:** Reduces response time and saves 50%-70% of human workload for Sales and Support teams.
- **Knowledge Management:** Easy upload and indexing of support documents for AI training.

## Prerequisites

- [Node.js](https://nodejs.org) (v20+)
- [pnpm](https://pnpm.io)
- [Turbo](https://turborepo.dev)

## Installation

```bash
pnpm install
turbo dev
```
